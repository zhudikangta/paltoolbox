# 伙伴技能折叠计数与滚动性能设计

## 目标

伙伴技能筛选栏的九个用途大类在展开和折叠状态下都显示当前可匹配的帕鲁总数；同时保留左右两栏共用一张大卡片的挖洞外观，消除滚动时反复生成整张遮罩造成的额外开销。

## 数量口径

- 大类数量按帕鲁去重。
- 一只帕鲁同时命中同一大类的多个子选项时只计一次。
- 数量受当前帕鲁来源、帕鲁或技能搜索、已经选择的全部筛选条件共同影响。
- 大类自身已有选项被选中时，数量表示当前结果中命中该大类的帕鲁数。
- “查找筛选项”只控制筛选项的显隐，不改变伙伴技能结果，因此不改变大类数量。

## 遮罩结构

- 保留 `.sk-partner-browser` 作为底层统一大卡片。
- 在大卡片中放置一个只保存遮罩定义的内联 SVG。
- 页面初次渲染、尺寸改变、筛选结果重绘和折叠动画期间，重新测量孔洞并更新 SVG。
- 左右滚动区各自拥有一个孔洞组。滚动时只修改对应孔洞组的 `transform` 位移，不重新拼接 SVG 字符串，不重新写入遮罩图片。
- 左右滚动区仍由固定裁剪区域约束，孔洞不会越过各自滚动视口。

## 修改范围

- 核心筛选逻辑：增加大类去重计数。
- 伙伴技能网页适配：渲染大类数量，替换滚动期遮罩重建逻辑。
- 伙伴技能样式：补充大类数量样式和隐藏的 SVG 定义容器样式。
- 自动检查：覆盖去重计数、动态筛选计数和滚动期不重建遮罩。

不修改伙伴技能分类数据、筛选“且”逻辑、伙伴技能卡片内容、帕鲁图鉴和全局视觉设置。

## 验收

- 选择“地面骑乘”后，其他折叠大类仍显示当前可匹配的去重数量。
- 展开和收起大类时数字始终可见。
- 连续滚动左栏或右栏时，`--sk-partner-frame-mask` 不被逐帧重写，只有对应 SVG 孔洞组的位移变化。
- 孔洞与卡片保持对齐，左右两栏仍像同一张大卡片。
