# 伙伴筛选栏交互修正设计

## 目标

- 筛选栏自绘滚动条向左移动 6px，继续复用全局自绘滚动条。
- 左侧筛选区与右侧结果区之间显示独立的 1px 分割线。
- 点击筛选项重新渲染后，左侧筛选栏保持原有滚动位置。
- 删除结果区两种“所选条件必须全部满足”提示，保留已选条件标签和实际的交集筛选逻辑。

## 实现边界

- 只修改伙伴技能网页适配、伙伴技能专用样式和对应自动检查。
- 不修改共享自绘滚动条模块，不修改帕鲁图鉴，不修改伙伴技能数据及分类。
- 不新增挖洞层；分割线是网格中的独立布局元素，现有大卡片挖洞实现保持不变。

## 技术方案

1. 初始化共享自绘滚动条后，为筛选栏对应的滚动条增加伙伴技能专用类，通过 `translateX(-6px)` 调整显示位置。
2. 伙伴技能主网格改为“筛选栏 / 1px 分割线 / 结果区”三列；窄屏回到单列并隐藏分割线。
3. `rerender()` 替换页面内容前记录 `.sk-partner-filter-sidebar.scrollTop`，替换后先恢复滚动位置，再绑定滚动条和挖洞逻辑。
4. 删除提示文本的生成变量、HTML 和废弃样式；已选条件标签及筛选核心不变。
