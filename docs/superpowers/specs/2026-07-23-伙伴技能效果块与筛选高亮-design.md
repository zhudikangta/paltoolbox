# 伙伴技能效果块与筛选高亮设计

## 目标

伙伴技能卡片不再把所有分类标签统一堆在卡片顶部，也不再依据原始换行机械分割描述。每个标签应靠近它真正对应的技能描述；用户在左侧选择筛选条件后，右侧卡片应直接指出命中的是哪一项效果。

本次保留已经建立的伙伴技能分类体系，不重新设计分类名称、筛选层级或组合逻辑。

## 范围

本次改动仅覆盖伙伴技能工具：

- 整理正式目录中 301 条伙伴技能的效果块。
- 将现有具体分类标签绑定到对应效果块。
- 修复同一完整语义被错误换行、分割的问题。
- 在筛选命中后高亮对应标签和描述块。
- 为数据完整性、筛选汇总和页面呈现增加自动检查。

本次不包含：

- 不修改帕鲁图鉴的外观或详情页职责。
- 不重做现有伙伴技能分类体系。
- 不调整筛选条件的“且”逻辑。
- 不改变等级表的内容、位置和“展示详情”开关。
- 不改其他工具。

## 现状与问题

正式伙伴技能数据目前主要保存完整 `description`，分类数据则保存在卡片级的 `usageSubcategoryIds` 和 `usageTagIds` 中。网页把描述中的每个换行都渲染成一个段落，并在相邻段落之间加分割线。

这会产生两个问题：

1. 原始换行不一定代表独立效果。极道蛙的“积蓄力量”和“玩家踩上去后高高跳起”本是一项完整跳板动作，却被错误分开。
2. 分类标签只有卡片级归属，页面无法知道某个标签具体对应哪段描述，因此筛选命中后也无法指出命中的效果。

## 数据设计

### 效果块

每条伙伴技能增加结构化的效果块。每个效果块至少包含：

```json
{
  "text": "完整的一项效果描述。",
  "subcategoryIds": ["move.special"],
  "tagIds": []
}
```

规则如下：

- `text` 必须是一项语义完整的效果，可以包含多句话。
- 同一前提条件下没有说完的连续句必须放在同一效果块。
- 独立触发条件、独立常驻效果或另一种用途另建效果块。
- `subcategoryIds` 和 `tagIds` 只保存该效果块真正对应的分类。
- 不通过页面关键词或标点运行时猜测效果块。

### 兼容现有使用方

- 完整 `description` 由效果块按顺序合成，继续供帕鲁图鉴、搜索和现有读取逻辑使用。
- 卡片级 `usageSubcategoryIds` 和 `usageTagIds` 由所有效果块的标签取并集生成，继续供现有筛选核心使用。
- 效果块是标签与描述关系的唯一可信入口，避免卡片级分类与实际描述发生漂移。

### 标签显示规则

卡片只显示最具体的可筛选标签：

- 显示“地面骑乘”时，不重复显示其上级“骑乘”和“移动与骑乘”。
- 显示“骑乘二段跳”时，不重复显示其上级“骑乘跳跃”。
- 互不属于上下级关系的标签不能合并或隐藏，例如“特殊机动”和“玩家整体攻击力”必须分别显示在对应效果块上。

本次不会重新设计现有分类。人工复核中只修正明确的错误、重复或缺失，并保留逐项记录。

## 两只青蛙的标准分块

### 武道蛙

效果块一，标签为“特殊机动”：

> 发动后，武道蛙会靠忠诚心和膨胀的腹部积蓄力量。玩家在踩上去后能高高跳起。

效果块二，标签为“玩家整体攻击力”：

> 在落地前，玩家的攻击力提升(50~86)%。

### 极道蛙

效果块一，标签为“特殊机动”：

> 发动后，极道蛙会靠忠诚心和膨胀的腹部积蓄力量。玩家在踩上去后能高高跳起。

效果块二，标签为“弱点部位伤害”和“当前出战帕鲁攻防”：

> 若它在队伍中，玩家和帕鲁以暗属性攻击命中敌方弱点时的伤害提升(25~40)%。（不可叠加）

只有两个独立效果块之间显示分割线，第一块内部不显示分割线。

## 卡片呈现

伙伴技能卡片保留现有头像、编号、帕鲁名称、伙伴技能名称、卡片材质和主题。

身份信息下方按顺序渲染效果块：

1. 对应标签行。
2. 完整效果描述。
3. 下一项独立效果开始前显示分割线。

原来统一位于卡片顶部的分类标签行删除，避免同一标签出现两次。

等级表仍位于全部效果描述之后，并继续由“展示详情”按钮控制。

## 筛选命中高亮

左侧选中的每个筛选项与效果块的标签标识直接匹配：

- 命中的具体标签使用当前主题的选中颜色。
- 命中标签所属的整个效果块增加轻微底色和左侧亮线。
- 同一张卡片中不同筛选条件命中不同效果块时，各效果块分别高亮。
- 没命中的效果块保持正常显示，不降低透明度。
- 不给整张卡片统一染色，避免用户误以为卡片中的每项效果都满足当前条件。

## 人工复核

正式目录中的 301 条伙伴技能逐条检查：

- 描述是否按完整语义正确分块。
- 每个现有分类标签是否绑定到了正确效果块。
- 是否存在同一父子标签重复显示。
- 合成后的完整描述是否与确认后的正式内容一致。
- 多效果技能是否保留前提条件和不可叠加等限定语。

本轮复核不是重新分类。只有发现明确错分、重复或遗漏时才修正现有分类。无法从现有事实判断的内容写入冲突记录，不静默猜测。

## 自动检查

先增加能够失败的检查，再修改正式实现。检查至少覆盖：

- 301 条正式目录记录都有非空效果块。
- 每个效果块的分类标识都存在于正式分类体系。
- 卡片级分类等于效果块分类的去重并集。
- 效果块合成的完整描述没有丢字、重复或改变顺序。
- 武道蛙和极道蛙的跳板动作不会在中间出现分割线。
- 两只青蛙的独立增伤效果仍单独成块。
- 选择筛选项后，只高亮真正包含该标签的效果块。
- 多个筛选条件分别命中同一卡片的不同效果块时，各自正确高亮。
- 未选择筛选条件时，不显示命中高亮。
- 等级表和“展示详情”行为保持不变。

## 肉眼验收

打开伙伴技能页面：

1. 搜索“武道蛙”和“极道蛙”，确认跳板动作内部没有分割线，独立增伤效果前有分割线。
2. 确认每项效果的标签紧贴在对应描述上方，卡片顶部不再重复堆放全部标签。
3. 在左侧选择“特殊机动”，确认两只青蛙的跳板效果块高亮，增伤效果块保持正常。
4. 选择能够在同一卡片不同效果块中命中的多个条件，确认对应效果块分别高亮。
5. 切换“展示详情”，确认等级表只按原有开关显示或隐藏。
6. 切换卡片主题和材质，确认新增高亮仍使用当前主题颜色。
