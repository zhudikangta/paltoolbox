# 伙伴筛选栏交互修正 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修正伙伴技能筛选栏的滚动位置、滚动条位置、左右分区和冗余提示。

**Architecture:** 继续复用共享自绘滚动条与现有整页渲染方式，仅在伙伴技能适配层保存筛选栏滚动位置。分割线作为主网格的语义化布局元素，不介入现有大卡片挖洞遮罩。

**Tech Stack:** 原生 JavaScript、CSS、Node.js `assert`

### Task 2: 修改原实现

**Files:**
- Modify: `PalToolbox/游戏内容/幻兽帕鲁/工具功能/技能/网页模式适配/技能网页.js`
- Modify: `PalToolbox/游戏内容/幻兽帕鲁/工具功能/技能/样式/技能网页样式.css`

- [x] **Step 1: 调整自绘滚动条**

调用 `PT_initCustomScrollbars(sidebar)` 后，从 `sidebar._ptCustomScrollbarState.bar` 取得共享滚动条节点并添加 `sk-partner-filter-scrollbar` 类；样式使用 `transform:translateX(-6px)`。

- [x] **Step 2: 增加网格分割线**

主网格使用 `minmax(250px,300px) 1px minmax(0,1fr)`，在筛选栏与结果区之间渲染 `sk-partner-browser-divider`，窄屏隐藏。

- [x] **Step 3: 保留左侧滚动位置**

`rerender()` 在替换内容前读取筛选栏 `scrollTop`，替换后将同一数值赋给新的筛选栏，再执行 `bind(content)`。

- [x] **Step 4: 删除冗余提示**

删除 `selectedLabels`、`summaryHtml`、两句提示 HTML 和 `.sk-partner-filter-summary` 样式，保留 `appliedHtml` 与筛选核心。
