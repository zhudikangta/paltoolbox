# 伙伴技能折叠计数与滚动性能 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为伙伴技能折叠大类显示按帕鲁去重的动态数量，并让滚动只移动现有孔洞组而不重建整张遮罩。

**Architecture:** 核心层从当前筛选结果计算每个用途大类的去重数量，网页层只负责展示。外观层使用一个持久内联 SVG 遮罩；布局变化时重建孔洞，滚动时仅更新左右孔洞组的平移。

**Tech Stack:** 原生 JavaScript、CSS、HTML、Node.js 断言测试、浏览器页面验证。

- [ ] **Step 3: Write minimal implementation**

在核心层复用 `filterPartnerSkills` 得到当前结果，再检查每只帕鲁是否命中大类内任一选项：

```js
function getPartnerFacetGroupCounts(filters) {
    var filtered = filterPartnerSkills(filters || {});
    var counts = {};
    partnerFacetGroups.forEach(function(group) {
        counts[group.id] = filtered.filter(function(item) {
            return group.facets.some(function(facet) {
                return facet.options.some(function(option) {
                    return itemMatchesPartnerOption(item, option);
                });
            });
        }).length;
    });
    return counts;
}
```

将函数加入 `PT_SKILL_CORE` 的公开接口。
